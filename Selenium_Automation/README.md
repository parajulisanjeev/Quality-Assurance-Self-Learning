## Installation

Install Selenium using pip:

```bash
pip install selenium
```

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Move into the project folder:

```bash
cd Selenium_Automation
```

Run a Python Selenium script:

```bash
python login.py
```
